# Reālistisko dekoru kolekcija

Visi 61 esošie dekori pārveidoti ar iebūvēto imagegen rīku. Saglabāti dekoru identifikatori, nosaukumi, grupas un lietotāju novietojuma iestatījumi.

- Caurspīdīgs WebP; garākā mala līdz 512 px, uzlīmēm līdz 256 px.
- Kopējais apjoms: 1.69 MiB; par 26% mazāk nekā iepriekš.
- Vecie faili paliek mapē ../optimized; izvēlne lieto šo jauno kolekciju.
- Nav jaunu animāciju; izvēlnes attēli ielādējas pēc vajadzības.
