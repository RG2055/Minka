# RG Radio skin sources

The runtime assets in this folder are locally cropped and compressed to 2400 × 400 pixels.
The 720 × 120 `*-preview.jpg` derivatives keep the selector lightweight; the full image is loaded only for the selected skin.

- `mist-forest-2400x400.jpg` — “Moody Forest Landscape with Misty Atmosphere” by Berke Çetin, [Pexels](https://www.pexels.com/photo/37265747/), Pexels License.
