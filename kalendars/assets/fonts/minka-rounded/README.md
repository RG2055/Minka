# Minka Rounded digits

Static numeral subset of [Fredoka from Google Fonts](https://github.com/google/fonts/tree/main/ofl/fredoka), distributed under the accompanying SIL Open Font License.

Built from Fredoka[wdth,wght].ttf with fontTools 4.60.2: instantiate weight 700, width 100; subset to digits 0–9, colon, period and space; rename family to Minka Rounded; encode as WOFF2. File size: 1,916 bytes. The original reserved family name is not used by this modified font.

Only the Plūsma and Perlamutrs finishes use this font. Existing finishes retain their typography.
