# M3 digits

`digits.woff2` is a 13 kB cut of **Google Sans Flex** (Copyright 2015 Google LLC,
SIL Open Font License 1.1, see `OFL.txt`; no Reserved Font Name is declared).

Modified: only the glyphs `0–9 : – - h` and space are kept; the optical size is fixed
at 144 and the slant/grade axes at 0; width (25–100), weight (300–800) and roundness
(0–100) stay variable. Used by the M3 clocks on the cards (card-faces.js, skins f–h
and p–t); the browser only fetches it when such a clock is on screen.
